
# Pequenas Atitudes, Grandes Transformações

## Sobre o projeto
Projeto educativo sobre meio ambiente, sustentabilidade e preservação dos recursos naturais.

## Objetivo
Incentivar atitudes sustentáveis e conscientizar sobre a importância de cuidar do planeta.

## Temas abordados
- Reciclagem e reutilização de materiais.
- Economia de água.
- Preservação da natureza.
- Consumo consciente.
- Sustentabilidade.

## ODS 12
Consumo e Produção Responsáveis.

## Importância
Pequenas mudanças no cotidiano podem contribuir para um futuro mais sustentável.
